# Mobile & Embedded Systems Portfolio — William Wallace

Senior native mobile engineer with embedded firmware roots. Specializing in high-consequence Bluetooth (BLE) hardware integrations, medical device software (IEC 62304 / ISO 14971), and real-time sensor telemetry.

## Featured Regulated & Hardware Projects

### [MyCite — Otsuka Pharmaceutical](projects/mycite-otsuka.md)
* **What it is:** Digital medicine system pairing an ingestible pill sensor and wearable patch to track adherence.
* **My Role:** Built the BLE communication layer interfacing with the wearable sensor patch; implemented local data ingestion and session adherence pipelines.
* **Stack:** `Swift` `CoreBluetooth (BLE)` `Unit Testing` `CI/CD` `REST APIs`

### [Shadow Drive Connect — Vonnen](projects/shadow-drive-vonnen.md)
* **What it is:** Companion app for an aftermarket hybrid powertrain upgrade (150 hp electric motor) on Porsche 911s.
* **My Role:** Sole mobile engineer. Integrated the Bluetooth interface communicating with the vehicle's Engine Management Unit (EMU) for real-time telemetry, mode switching, and diagnostics.
* **Stack:** `Swift` `CoreBluetooth` `Embedded C` `Real-Time Telemetry` `MVC`

* **What it is:** Clinically validated digital health app capturing sensorimotor data for multiple sclerosis research.
* **My Role:** Built sensor-based active test interfaces and patient flows with comprehensive unit/UI test coverage.
